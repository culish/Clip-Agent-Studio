YT Clips — Clip Agent Studio

A desktop app for creators. It turns long videos into vertical short clips with subtitles, helps write original scripts, and uploads finished videos to the creator's own channels.

What the app does

  • Cuts long videos into short clips with animated English subtitles.
  • Writes original short-video scripts, adds voice-over, visuals, music and captions.
  • Makes covers, cartoon-style animations and automatic edits (B-roll, music, captions).
  • Uploads finished videos, when the user clicks Post, to the YouTube channels, Facebook Pages, Instagram accounts and TikTok accounts that the user connected.

How it uses Google and YouTube data

YT Clips runs on the user's own computer. When a user connects a YouTube channel, the app asks for permission to upload videos (youtube.upload) and to read the channel name (youtube.readonly). It uses these permissions only to show which channel is connected and to upload videos the user selects. Access tokens are stored only on the user's computer and are never sent to the developer. Details are in the Privacy Policy.

By connecting a YouTube channel you agree to the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.
