Posting ke banyak akun YouTube, Facebook, Instagram, dan TikTok

      
Hubungkan sebanyak mungkin channel dan akun, lalu pilih akun tujuan untuk tiap video. YouTube dan Facebook menayangkan sesuai jadwal walau laptop mati; jadwal Instagram dan TikTok dijalankan Clip Agent, jadi aplikasi harus menyala pada waktunya.

    

  

  

    

      
Posting baru

      
      
      
Akun tujuan
        

      

      
      
      
      

        
        
      

      
      

      
Kosongkan "Kapan" untuk langsung posting. Jadwal YouTube minimal 15 menit dari sekarang, Facebook 10 menit–29 hari.

      

      
Antrean posting

      

    

    

      
Akun terhubung

      

        
YouTube

        

        

          
          
        

        

        
Cara membuat OAuth Client (sekali saja, ±10 menit)
          
    
            
  1. Buka console.cloud.google.com, buat proyek baru.
    2. 
            
  2. APIs & Services → Library → aktifkan YouTube Data API v3.
    3. 
            
  3. Google Auth Platform → Audience: pilih External, lalu tambahkan semua email Google pemilik channel di Test users (atau klik Publish app).
    4. 
            
  4. Clients → Create client → jenis Desktop app. Salin Client ID dan Client Secret ke sini.
    5. 
            
  5. Klik Tambah channel YouTube dari browser di laptop, pilih akun dan channel, lalu izinkan. Ulangi untuk channel lain; pilih akun/channel lain di layar login Google.
    6. 
          

          
Satu Client bisa dipakai untuk banyak channel. Selama status Testing, izin berlaku 7 hari; klik Publish app agar tidak kedaluwarsa.

        

      

      

        
Facebook & Instagram

        

        

        
        

          
          
        

        

        
Cara mendapatkan token
          
    
            
  1. Instagram harus akun profesional (Business/Creator) yang terhubung ke Facebook Page.
    2. 
            
  2. Buka developers.facebook.com → My Apps → buat aplikasi jenis Business.
    3. 
            
  3. Graph API Explorer → pilih aplikasi → Get User Access Token dengan izin: pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish, business_management.
    4. 
            
  4. Centang semua Page yang ingin dipakai saat diminta. Semua Page dan akun Instagram yang terhubung akan ditambahkan sekaligus. Hapus yang tidak perlu dari daftar.
    5. 
            
  5. Untuk akun Facebook lain, buat token dari akun itu lalu klik Tambah dari token lagi.
    6. 
          

          
Isi App ID dan App Secret agar token diubah menjadi jangka panjang (token Page dari situ tidak kedaluwarsa). Batas: Facebook Reels 30 posting/24 jam per Page, Instagram 100/24 jam, Reels Facebook 3–90 detik.

        

      

      

        
TikTok

        

        

          
          
        

        

        
Cara membuat aplikasi TikTok (sekali saja)
          
    
            
  1. Daftar di developers.tiktok.com → Manage apps → Connect an app.
    2. 
            
  2. Tambahkan produk Login Kit (platform Desktop) dan Content Posting API; aktifkan Direct Post.
    3. 
            
  3. Scope: user.info.basic, video.publish, video.upload.
    4. 
            
  4. Redirect URI Desktop: http://127.0.0.1:*/oauth/tiktok/ (persis, termasuk garis miring di akhir).
    5. 
            
  5. Salin Client Key dan Client Secret ke sini, lalu klik Tambah akun TikTok dari browser di laptop. Untuk akun lain, keluar dulu dari TikTok di browser, lalu tambah lagi.
    6. 
          

          
Sebelum aplikasi diaudit TikTok, Direct Post hanya bisa ke akun TikTok yang diset privat dengan privasi "Hanya saya". Mode "Kirim ke draf TikTok" mengirim video ke kotak masuk TikTok; Anda menyelesaikan posting di aplikasi TikTok. Ajukan audit agar bisa langsung terbit untuk publik.

Akses dari HP

          
        

        
HP dan laptop harus memakai Wi-Fi yang sama. Proses klip tetap berjalan di laptop; HP menjadi remote untuk membuat, memantau, dan mengunduh klip.

        

          

            

            

              Alamat
              Kode akses
            

          

          
    
            
  1. Pindai QR dengan kamera HP, lalu buka tautannya.
    2. 
            
  2. Pilih Unduh aplikasi Android untuk memasang APK, atau Lanjut di browser.
    3. 
            
  3. Di aplikasi, masukkan alamat dan kode di atas (atau pindai QR lagi lalu pilih Buka di aplikasi).
    4. 
          

          
Bila Windows menampilkan peringatan firewall untuk Python, centang Private networks lalu pilih Allow. Pastikan profil Wi-Fi laptop diatur sebagai Private.
